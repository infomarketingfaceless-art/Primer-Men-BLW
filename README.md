# MI PRIMER MENÚ BLW — versión visual para pruebas

## Cómo subir a GitHub Pages
1. Extraer este ZIP.
2. Crear repositorio en GitHub y subir **todos los archivos y la carpeta assets** a la raíz.
3. Settings > Pages > Deploy from a branch > main / root.
4. Probar en móvil.

## Incluye
71 recetas y 210 jornadas rotativas (30 por edad, 6–12 meses), menús editables, compras, favoritos, registro, perfil, diario, respaldo, PWA y seis imágenes ilustrativas de alimentos generadas a partir del concepto visual. Las imágenes **no corresponden necesariamente a la receta que acompañan**: deben sustituirse por fotografías específicas antes de comercializar.
